PhotoSizer

Resize a batch of images locally, choose social image presets, and download the results together.

Open working demo ↗

The problem

Preparing several photos for different uses can require repetitive resizing and file handling. The product keeps the process in one local browser tool.

What it does

  • Reads JPG, PNG, and WebP images locally.
  • Preserves proportions, with custom sizing or exact-size preset canvases.
  • Offers padding or center cropping and exports a ZIP of new copies.
  • Leaves original files unchanged.

Implementation

HTML, CSS, JavaScript, browser Canvas, and a local ZIP writer. Developed with AI assistance. Source is included in the portfolio repository.

Validation & limits

Automated checks cover sizing, enlargement, cropping geometry, filenames, and ZIP integrity. The owner has reviewed the interface. Complete cross-browser image export testing remains outstanding. Exports remove metadata; browser memory limits apply.

Project status

A packaged personal product, not a Webflow project or client engagement. No sales or usage results are claimed.
