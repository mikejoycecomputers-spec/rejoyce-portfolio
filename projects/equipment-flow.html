The problem

Equipment handoffs need a clear record of who holds an item, where it belongs, and what happened when it moved. A useful tool must also accommodate scanning hardware, phones, and disconnected devices.

The application

  • Equipment checkout and return workflows, with storage locations and employee assignments.
  • Barcode scanning and companion phone pairing.
  • Offline transfer queues that synchronize on reconnection, with conflicts held for review.
  • Technician intake for unrecognized items and administrator review.
  • Scan-sheet reporting and spreadsheet export.
  • Engineering shipment and package receiving records.

Technical foundation

Next.js, PostgreSQL, and a browser-based offline workflow. The project combines a responsive interface with server-side sessions and authorization. Source code is maintained in a private GitHub repository.

Scope and status

This showcase summarizes the implemented features documented in the project repository. It is not a production audit or a claim about adoption, measured results, or independent validation. The live application is intended for authorized users; this portfolio does not expose operational records or source code.
