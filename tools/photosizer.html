2. Choose your size

Presets set canvas dimensions, not upload file-size limits. These are image exports, not videos. Check the platform preview before posting.

Proportions are always preserved. Easy mode can crop edges or add padding; Custom mode never crops. Quality does not apply to PNG. Output file size may increase; smaller dimensions do not guarantee a smaller file.
