Stillwell — ReJoyce HTML template

Open index.html. Includes Home, Services/Collection, Contact, CSS, JavaScript, and original SVG illustrations.
Edit colors in site.css and text in the HTML files. Contact form is a local preview only; connect a real form backend before launch. Replace fictional content with accurate business information.
Responsive layouts, visible focus, semantic headings, and reduced-motion styles are included. Test on your target devices before publication.
No external libraries, tracking, stock images, or fonts. SVG artwork is original code.
This is an HTML template, not a native Webflow project. Native Webflow conversion, CMS, checkout, hosting, and backend integrations are not included.
